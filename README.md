# Hidden Genius Showcase

Build a professional, modern web application called “Hidden Genius”.

🎯 Purpose

A platform for college students to showcase, verify, and gain recognition for non-academic skills (like leadership, creativity, projects, extracurriculars), which are usually ignored in traditional academic systems.

👥 Target Users

 Students (primary users)

 Faculty / HODs (verification)

 Recruiters (view talent)

🧠 Core Features

1. Authentication

 Sign up / Login system

 Role selection (Student / Faculty / Recruiter)

2. Student Dashboard

 Profile with:

 Name, course, year

 Skills section

 Projects / achievements

 Add new skill button

 Upload proof (certificate / project description)

 Status: Pending / Verified

3. Faculty Dashboard

 View student submissions

 Approve / Reject skills

 Add comments

 Simple verification panel

4. Recruiter Dashboard

 Browse student profiles

 Filter by skills

 View verified skills only

 Simple search bar

5. Skill Verification System

 Students upload skills

 Faculty verifies

 Verified badge appears on profile

🎨 UI / DESIGN REQUIREMENTS (VERY IMPORTANT)

Make the design:

 Clean, minimal, and modern

 Use soft colors (teal, blue, purple tones)

 Rounded cards and smooth shadows

 Professional typography (no childish fonts)

 Dashboard-style layout

Include:

 Sidebar navigation

 Cards for skills

 Icons for sections (skills, profile, verification)

 Smooth spacing and alignment

Avoid:

 Clutter

 Too many colors

 Complex animations

📱 Pages Required

 Landing Page

 Title: “Hidden Genius”

 Tagline: “Show your skills beyond grades”

 Call-to-action: Get Started

 Login / Signup Page

 Student Dashboard

 Faculty Dashboard

 Recruiter Dashboard

⚙️ Technical Instructions

 Make it functional (not just design)

 Use simple working logic (no need for backend database, use mock data if needed)

 Ensure navigation between pages works

 Responsive layout (works on laptop screen)

💡 Extra (if possible)

 Add “Verified Badge” on approved skills

 Add simple loading or hover effects

 Use cards for better UI

🚀 Final Output

 A clean, working website UI

 Clear structure and navigation

 Looks like a real startup product
